L4 (WP-802 design, 2026-11-13): acceptance-set correction (explore): upstream RPC @ 085c84e has NO init/tool_result/quit commands — init = client `start()` (spawn only), `prompt` is the only acceptance command, tool-result = events the client OBSERVES (`tool_execution_start/end` correlated by `toolCallId` + `toolResult`-role messages; the core feeds results to the model autonomously), quit = client `stop()` = SIGTERM → exit 143. No handshake; strict LF JSONL.
- `--mode rpc` = new `OutputMode::Rpc`: same stdout writer as Json (`json_tx`), no session header line, kind events off, `--prompt`/`--scenario` not required, the core idles on stdin.
- Command loop (core, new `rpc_command_loop`): `prompt {message, streamingBehavior?}` → `{id, type:"response", command:"prompt", success, data:{disposition}}` — "started" idle; "queued" when a run is active + streamingBehavior; exact upstream error string when active without behavior; unknown command → `success:false, error:"Unknown command: <type>"`; parse failure → `"Failed to parse command: …"`.
- v0 deviations (recorded): disposition is pre-queue (no preflight/`input`-decision round trip before the response), `images` accepted-but-unmapped (corelog warning), steer/followUp queues a FOLLOW-UP run instead of a mid-turn steer.
- Stream parity additions (also close `--mode json` gaps, same upstream `toJsonEvent` family): `turn_end {message, toolResults}` per turn; `message_start`/`message_end` for `toolResult` messages; `agent_settled {aborted:false}` after `agent_end` (the client's `waitForIdle`/`promptAndWait` gate on it).
- Shutdown: stdin EOF → clean sidecar shutdown, exit 0; SIGTERM → clean sidecar shutdown, exit 143 (upstream parity).
- Tests (tests/rpc.rs): (1) echo-mode prompt round-trip incl. unknown-command error + EOF exit 0; (2) tool-event correlation via mock OpenAI SSE (toolCallId across tool_execution_start/end + toolResult message events, 2 turns, agent_settled); (3) UPSTREAM RpcClient (dist) drives pi-rust through a node shim cliPath (promptAndWait → events incl. agent_settled; stop → 143); (4) protocol diff vs upstream `dist/cli.js --mode rpc` against identical mock providers (normalized line type + key sets; diff must be empty for the prompt command).
